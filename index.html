Score a bispecific antibody target pair

Type two gene targets. This queries a live FastAPI backend running an XGBoost model trained on 328 real, unique target pairs derived from 782 actual bispecific antibody drug programs (the paper's own Supplementary Table 1 — ClinicalTrials.gov-sourced clinical-stage data).

This baseline model was trained only on drug-program popularity and structural features (how many programs/orgs have tried a target, CD3 involvement, checkpoint-gene membership) — not the paper's full biological feature set (safety score, co-expression, pathway overlap, Gene2Vec similarity), since that requires scRNA-seq/KEGG/Gene2Vec data this pipeline hasn't been given yet. Known approved pairs will score high almost by construction; treat scores for genuinely novel pairs as a weak prior, not a validated prediction.
